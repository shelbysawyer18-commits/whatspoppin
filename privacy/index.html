What's Poppin?

Privacy

What's Poppin? is a fan-made movie rating card site. It is not a corporate product page and is not affiliated with theatre chains, studios, or The Movie Database (TMDB) as a partner.

Sign-in

When cloud sign-in is enabled, you can use:

  • Email magic link (one-tap sign-in; no password collected by this app)
  • Google sign-in for identity, when that option is turned on
  • X sign-in for identity, when that option is turned on

Google sign-in is requested only for basic identity: OpenID, public profile, and verified email. This site does not ask for your Google password, payment card, private Gmail, Drive, or feed content. X OAuth, when enabled, is likewise used for identity through the auth provider. An X / Twitter username typed into your profile is a display handle only — it is not a verified X login.

Authentication is handled by Supabase Auth. This app's own code does not store OAuth provider access tokens from the client auth session.

What we store

  • Account id from the auth provider (your signed-in user id)
  • Email associated with magic-link or OAuth identity (held by Auth)
  • Optional profile username / display handle you choose
  • Optional avatar image you upload
  • Favorites and Not for me snack/drink tags
  • Review card content you save (movie selection, bags, candy, drink, three words, optional photo)
  • Technical session / account metadata needed to keep you signed in

On this device

Profile preferences and card drafts may be saved in this browser's local storage so the site works offline or before you sign in. The auth client also persists a session in the browser so you stay signed in across visits. Clearing site data in your browser removes that local copy.

Third parties used by the service

  • Supabase — authentication and cloud profile/card storage
  • TMDB — movie search and poster images already used by the card builder
  • Vercel — hosting this site
  • X — only when you choose to open or share a post there

This site does not sell personal information and does not run separate advertising or marketing trackers in its own code.

Account and data removal

While signed in, open Your profile and use Account & data to delete your account. That removes your auth user and cascaded cloud profile/card rows, and removes profile photos stored for your account. You can also sign out, or clear this site's data in your browser to remove local drafts and preferences on this device.

A separate public contact inbox for account requests is not published on this page. Use the in-app delete control when signed in.

This page describes how What's Poppin? works today. It is not a guarantee about retention length, legal classification, or certifications.
